# 亚马逊关键词架构

读取已保存的关键词数据、站点、周期、指标定义、产品用途及已验证产品事实。保留原始词、原始指标、来源和记录定位。新的记录按原始数据的保留规则追加，处理结果另存。

1. 按项目提供的关键词清洗脚本和规则版本处理大小写、单复数、词根、品牌词和风险词，保留原词与归并结果的对应关系。脚本或规则缺失时，输出待校验的人工分组建议，并保留原始值和尚未执行的规则项。
2. 依据真实产品事实判断意图、使用场景和匹配程度。把相关词、待核验词和排除词分别记录，说明与产品、品牌或声明限制的关系。各来源指标按定义和周期保留，口径不同的数据分别报告。
3. 将可用词映射到标题、五点、描述或 Search Terms，记录位置与理由。排除不适配词、竞品品牌词及需要证据而当前无法证实的词。

交付可追溯的关键词表，包含原词、规范词、来源、指标及口径、意图、相关性、目标位置、理由和处理状态；记录清洗规则版本及待校验项。
