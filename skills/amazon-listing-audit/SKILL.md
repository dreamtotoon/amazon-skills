# 亚马逊 Listing 审核

读取待审标题、五点、描述和 Search Terms，以及对应站点、类目、产品事实、关键词来源和适用的规则或校验工具。原稿保留版本。缺失的输入及其影响按审核项记录。

1. 逐项对照材质、尺寸、数量、颜色、包装内容、适配性和功能声明。标出草稿原文、事实字段、证据位置及冲突。遇到未知、假设或无依据声明，保留为待核验问题。
2. 核对关键词来源、产品相关性及竞品品牌等风险。根据站点、类目和用户提供的规则检查禁用声明、格式与长度；可执行的确定性规则使用对应校验工具。记录工具、规则版本、输入和检查结果。缺少适用规则或工具时，列明未检查项。
3. 输出问题清单，列出位置、原文、问题、证据、修改建议和处理状态。区分已通过项、待修改项和待核验项。每个问题应修改后复核，或记录适用规则允许的主管豁免，见[人工审批记录](references/approval-record.md)。

提供审核结论及其覆盖范围。存在待核验项目或未解决的问题时，保留相应状态。实际发布由获授权人员执行。
