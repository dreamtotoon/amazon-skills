# 亚马逊 Listing 文案

读取站点、类目、语言、已验证产品事实、确认过的关键词和适用的字段规则。用户未指定站点时先按美国站准备草稿，在交付中写明该假设。事实尚未核验时，先标出受影响的字段，只拟写现有证据支持的部分。

1. 提取可以进入文案的事实，保留与证据的对应关系。把关键卖点自然地分配到标题、五点及描述，按已确认的相关性和位置分配关键词。
2. 生成标题、五点、描述及 Search Terms。按已知站点和类目规则核对格式、长度与词汇限制；标出未核实的约束。避免把内部证据编号或待确认标记放进可复制的文案正文。
3. 复核功能、认证、兼容性、材质、尺寸、数量和包装信息是否有对应证据。省略无法证实的事实、绝对化承诺和未经确认的竞品信息。

交付分字段草稿、关键声明的事实或证据索引，以及影响下一轮修订的缺失项。保持草稿状态，供成员审核后使用。
