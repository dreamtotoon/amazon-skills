# 亚马逊产品事实核验

确认产品、规格版本和销售站点。按产品或变体分别核对用户提供的规格、样品测量、经确认的供应商资料、检测文件或图片。预计规格、设计目标和供应商未验证宣称各自保留来源及状态。

1. 按[事实表模板](references/product-facts.yaml)记录字段。每个关键字段给出 `value`、`status`、`source`、`verified_by`、`verified_at`；数值附单位，来源定位到具体证据和适用版本。
2. 对照核验材质、尺寸、数量、颜色、包装、功能、适配性、认证及相关卖点。来源冲突时记录各值与证据，标明所需复核。缺失值记录为 `UNKNOWN`，尚待验证的假设标记为 `ASSUMPTION`。
3. 只有已核验或有依据的明确人工批准记录支持的声明可以列入文案候选。将 `UNKNOWN`、`ASSUMPTION` 与无来源的供应商宣称留在待核验清单。核验人及时间沿用证据中的实际记录。

输出事实表、可写入 Listing 的字段清单，以及冲突或缺失事实的验证动作。每个变体只引用适用于自身的证据。
