# 亚马逊图片策划与审核

读取用户提供的真实参考图、产品事实、销售站点、类目、变体和交付用途。先盘点哪些角度、尺寸、包装内容和关键结构有证据，记录图像来源和适用变体。

1. 按主图、尺寸、包装内容、关键结构、场景等实际所需图片编排 Storyboard。每张图列出目的、展示内容、来源素材、画面要求、可用文案和需要核验的事项。
2. 主图、尺寸图、包装内容图和关键结构图使用真实产品素材作为依据。AI 可辅助生成场景、背景或构图。涉及真实外观、结构、标签文字、尺寸和数量的部分与素材或事实表逐项核对。
3. 审核已有图片时，对照主体、变体、颜色、包装数量、尺寸文字、声明和适用的站点规则。证据不足时标记 `待核验` 并说明需要什么素材。没有适用版式或政策依据时，标明规则核验范围。

交付图片 Brief、Storyboard 与 QA 清单。QA 按图片列出要求、证据、待修正或待核验项和当前状态。
